Add FASTA input and output data files

Added test data files for bioinformatics analysis:
- raw_sequences.fasta: Contains unaligned protein sequences (11 sequences)
- msa_output.fasta: Contains aligned sequences produced by Clustal Omega

These real biological sequences serve as test inputs for module development,
enabling test-driven development of the consensus calculator, PSSM generator,
and sequence logo visualization tools. The aligned sequences in msa_output.fasta
demonstrate realistic gap patterns and amino acid distributions found in protein families.

Having test data early in development allows for immediate validation of each
module as it is implemented, following best practices for scientific software
development where reproducibility and testability are critical.
