Add sequence logo visualization with logomaker

Extended sequence_profile.py with sequence logo generation capability,
completing the PSSM analysis module. Sequence logos provide intuitive
visual representation of sequence conservation patterns, with letter
height proportional to information content at each position.

Implementation details:
- Added sequence_logo_creator() function using logomaker library
- Creates high-resolution PNG images (50x5 inches, 300 DPI)
- Uses 'chemistry' color scheme appropriate for amino acids
- Automatically scales figure dimensions based on alignment length
- Integrates seamlessly with existing PSSM calculation pipeline

Sequence logos are standard visualizations in bioinformatics publications
and presentations, making this essential for portfolio-ready scientific
software. The chemistry color scheme (hydrophobic, polar, charged) helps
biologists quickly identify functional patterns in alignments.

This completes the PSSM module as a separate commit because visualization
required additional testing with logomaker integration and figure formatting.
Keeping calculation and visualization separate allows easier debugging and
maintenance.

Verified by: Generated sequence logo PNG from msa_output.fasta and confirmed
visual output shows expected conservation patterns with proper color coding
and scaling.
