Add PSSM generation and sequence profile CSV export

Implemented sequence_profile.py script with sophisticated position-specific
scoring matrix (PSSM) generation functionality. This script builds upon the
basic consensus calculator by creating detailed probability distributions
for each position in the alignment.

Key features:
- calculate_sequence_profiles() function generates PSSM from aligned sequences
- Converts raw character counts to probability distributions at each position
- Filters gap characters (using lessons learned from step_05)
- Exports results to CSV with alphabetically sorted amino acid headers
- Uses pathlib for robust cross-platform path handling
- Configurable output prefix via MSA_OUTPUT_PREFIX environment variable

The PSSM output enables downstream analyses like motif discovery, sequence
comparison, and binding site prediction. Exporting to CSV allows easy import
into spreadsheet tools or statistical software for further analysis.

Visualization capability will be added in the next step to maintain separation
of concerns (calculation vs visualization) and allow independent testing of
each component.

Verified by: Script generates correctly formatted CSV file with probability
values that sum to 1.0 (or close due to floating point) for each position.
