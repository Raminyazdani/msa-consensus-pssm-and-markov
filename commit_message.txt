Implement discrete-time Markov chain simulation

Created markov_simulation.py implementing discrete-time Markov chain
simulator for modeling stochastic state transitions. While independent
of the sequence analysis modules, Markov chains are fundamental to
bioinformatics (e.g., hidden Markov models in sequence analysis).

Key implementation:
- simulate_markov_chain() function with numpy-based random sampling
- Accepts custom transition matrices and initial state distributions
- Runs multi-step simulations and reports state frequencies
- Example models traveler movement between Berlin, Munich, and Hamburg

The implementation demonstrates:
- Proper use of numpy for probabilistic calculations
- State transition mechanics following standard Markov chain theory
- Clear output formatting for interpretability

This module could be extended for more advanced applications like
modeling substitution patterns in sequence evolution or analyzing
state-dependent processes in biological systems.

Verified by: Ran 100-step simulation and confirmed state frequencies
converge toward stationary distribution, and transition probabilities
sum to 1.0 for each state (required for valid Markov chain).
