Implement consensus sequence calculation from MSA

Created consensus_sequence.py script that implements majority voting algorithm
for determining the consensus sequence from a multiple sequence alignment.

Key implementation:
- Uses BioPython's AlignIO for FASTA file parsing
- Iterates through each position in the alignment
- Counts character occurrences at each position using Counter
- Selects most common character as consensus

The script accepts a FASTA alignment file as command-line argument and prints
the resulting consensus sequence. This is the simplest module in the toolkit,
providing foundational sequence analysis functionality.

Known limitation: This initial implementation counts ALL characters including
gap characters ('-'), which may produce incorrect consensus when gaps are
predominant at certain positions. This will be addressed after initial testing.

Verified by: Script runs without errors on msa_output.fasta and produces output
(though output correctness will be validated in testing phase).
